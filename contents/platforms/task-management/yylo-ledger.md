YYLO Ledger is a Git-backed task store with a `yylo-ledger` CLI, where tasks carry dependencies and append-only history. A coding agent lists ready tasks, starts one, and records progress as plain Markdown commits, so every state change stays reviewable in Git. Wiki, workflow, and artifact records live in the same repository, keeping one clone as the source of truth.
