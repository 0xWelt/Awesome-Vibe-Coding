lavela is a deploy service (beta) that lets an AI agent, or a web console, put a GitHub repo on a live server and check on it afterwards. It builds the repo, runs it on a managed server, and adds managed Postgres, cron jobs, a custom domain you already own, and email authentication. It works as a remote MCP server for Claude, Claude Code, Cursor and other MCP clients (sign in with a lavela account), so vibe-coded apps can go from a chat to a live URL without wiring up infrastructure by hand. Pricing is a prepaid balance with no subscription; funds are added in the browser, never through the agent, and new accounts get a small starter credit.
