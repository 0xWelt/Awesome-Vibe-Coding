Publishes built React, Vite, Astro and HTML websites from a local directory or GitHub repository to an HTTPS URL. The same hosted service provides an OAuth MCP connector and an MIT-licensed publishing skill/plugin for coding agents to prepare uploads for owner review and confirmation, follow deployment status and inspect build logs. A Hobby account includes 3 projects, 20 publishes per month and custom-domain connections; compatible Next.js SSR requires a paid plan. It does not provision databases or run arbitrary backend servers.
