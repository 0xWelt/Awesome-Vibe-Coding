Webly is website hosting for AI agents. An agent publishes a vibe-coded website, or shares files and folders, at a live `*.webly.site` URL in seconds with no account needed to start; the person then signs in to claim it, and the agent keeps editing it over a hosted MCP server (Streamable HTTP, OAuth or API key) and publishes drafts the person approves. Sites can be plain static files or typed React source that Webly builds through a quality gate, with custom domains, version history and rollback, forms and analytics. It ships as an Apache-2.0 agent skill and plugin repo (github.com/Webly-AI/webly-plugin) with packages for Claude Code, Cursor, Codex, Gemini CLI and Hermes. The Free plan includes 25 sites; Hobby ($5/mo) and Pro ($20/mo) add custom domains and higher limits.
