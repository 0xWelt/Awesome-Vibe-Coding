deed.page gives a vibe-coded HTML page, report, dashboard or static site a permanent public URL in one request, with no account, no email code and no expiry. An agent sends one `curl` PUT or POST (a single file, a folder tarball or inline JSON) and gets back `https://<slug>.deed.page` plus a token for updating the same slug later. It ships as an MIT Agent Skill (github.com/f-o-x11/deed-page-skill) and a remote MCP server, so it works from Claude Code, Codex, Cursor and Gemini CLI. The Free plan needs no sign-up and includes one custom domain; the Hobby ($3/mo) and Pro ($15/mo) plans raise the limits.
