MCP server and agent plugin that audits npm packages for malware and AI-specific payloads before a coding agent installs them, and reports known vulnerabilities, maintainer history, license and transitive dependencies. Works with Claude Code, Cursor, Codex and any other MCP client, either from the plugin or against the read-only remote endpoint at `https://npmscan.com/api/mcp`. MIT.
