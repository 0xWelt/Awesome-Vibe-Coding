Hosted, read-only remote MCP server for CodeTrendy, a curated discovery directory of newly launched startups, SaaS tools and indie products, so Claude Code, Cursor, Codex and other MCP clients can look up existing products and alternatives while you build. Seven tools: `search_listings` (keyword search with optional category and pricing filters), `get_listing` (full listing profile), `find_alternatives`, `browse_category`, `list_categories`, `get_trending` and `get_site_of_the_day`. Add it with `claude mcp add --transport http codetrendy https://codetrendy.com/api/mcp`. Streamable HTTP, no API key and no account; docs at [codetrendy.com/mcp](https://codetrendy.com/mcp).
