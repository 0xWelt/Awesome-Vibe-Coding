Hosted, read-only remote MCP server for SitePatent, a human-reviewed launch and discovery directory of startups, tools and online products. It lets Claude Code, Cursor, Codex and other MCP clients search the listed websites, SaaS and AI tools, read full listing profiles, find alternatives to a named product and see what is trending. Seven tools: `search_listings`, `get_listing`, `find_alternatives`, `browse_category`, `list_categories`, `get_trending` and `get_site_of_the_day`. Add it with `claude mcp add --transport http sitepatent https://sitepatent.com/api/mcp`. Streamable HTTP, no API key and no account; docs at [sitepatent.com/mcp](https://sitepatent.com/mcp).
