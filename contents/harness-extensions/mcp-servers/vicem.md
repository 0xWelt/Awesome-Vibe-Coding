Zero-dependency local stdio MCP server (`npx -y vicem-cli mcp`), CLI, and agent skill that compacts coding sessions by 80–99% via deterministic AST code skeletonization and hands off a portable `.vicem/BATON.md` across Claude Code, Codex CLI, Cursor, Gemini CLI, Windsurf, and Antigravity in 3 seconds. Scores context on a `0–100%` salience scale (pinning explicit user constraints at `100%` and failed attempts at `88–95%`) and indexes stripped function bodies in `.vicem/ledger.json` so the receiving agent can restore any symbol losslessly via `vicem_rehydrate`. Runs 100% locally with zero network calls and entropy-based secret redaction.
