Hosted remote MCP server for ArtiGram, a free site where people publish what their AI made (HTML, React, SVG, Markdown, Mermaid) as live shareable pages. Claude Code, Codex and other MCP clients can search posts and read them without an account, and publish new ones with a free API key at `https://artigram.cafeboon.com/mcp`.
