MIT-licensed MCP server (stdio via `npx -y aria-icons`, or remote Streamable HTTP at https://icons.leularia.com/api/mcp with no auth) with 12 tools for searching ~1.4M open-source SVG icons (Lucide, Tabler, Heroicons, theSVG brand logos, 200+ Iconify sets) and adding them to projects as SVG or React/Vue/Svelte/Solid components.
