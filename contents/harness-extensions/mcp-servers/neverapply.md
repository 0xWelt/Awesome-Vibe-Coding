Hosted remote MCP server that lets Claude Code, Cursor, Cline and other MCP clients run a job search from the chat: search and match jobs, tailor resumes, answer screening questions, prepare for interviews, and apply to jobs with your approval (15 tools). It uses Streamable HTTP with OAuth 2.1 sign-in (PKCE and dynamic client registration), so there is no API key to paste. Add it with `claude mcp add --transport http neverapply https://neverapply.co/mcp`. Free plan available, with paid Pro and Max tiers; docs at [neverapply.co/features/mcp](https://neverapply.co/features/mcp).
