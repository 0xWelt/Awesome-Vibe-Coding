Native macOS app (Swift, MIT) with a built-in stdio MCP server that lets AI coding agents see and drive the Android Emulator and phones over adb. Its 18 tools cover screenshots and a UI tree in dp, tap/swipe/typing, logcat, an accessibility audit, and device settings such as dark mode, font scale, locale/RTL, TalkBack, network speed and location. Works with Claude Code, Codex, Cursor, VS Code and Gemini CLI. Install with `brew install --cask ateymoori/tap/oh-my-android`; needs macOS 26+ on Apple silicon and the Android SDK.
