Hosted, read-only remote MCP server for the MEDIAPRONET launch and discovery directory, so Claude Code, Cursor, Codex and other MCP clients can search newly launched startups, SaaS products and AI tools while you build. Seven tools: `search_listings` (keyword search with category and pricing filters), `get_listing`, `find_alternatives` (alternatives to a named product), `browse_category`, `list_categories`, `get_trending` and `get_site_of_the_day`. Add it with `claude mcp add --transport http mediapronet https://mediapronet.com/api/mcp`. No API key and no account; docs at [mediapronet.com/mcp](https://mediapronet.com/mcp).
