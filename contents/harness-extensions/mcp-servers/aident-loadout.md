Hosted remote MCP server, CLI and agent Skill that gives Claude Code, Codex, Cursor, Gemini CLI, OpenCode, ChatGPT and other MCP clients one shared set of connected apps and 400+ expert-built Skills. You connect accounts once and reuse them across every agent; credentials stay in Aident Vault and every action is recorded in an audit log. Add it with `claude mcp add --transport http aident https://loadout.aident.ai/mcp` or point any MCP client at `https://loadout.aident.ai/mcp` and sign in.
