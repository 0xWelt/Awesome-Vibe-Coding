Hosted remote MCP server that gives Claude Code, Codex, Cursor, Gemini CLI and other MCP clients YouTube data: video transcripts (pick the language, optional timestamps), YouTube search, a channel's videos, playlists and posts, playlist items and related videos. Add it with `claude mcp add --transport http getyoutubetranscript https://getyoutubetranscript.com/api/mcp --header "Authorization: Bearer YOUR_API_KEY"`.
