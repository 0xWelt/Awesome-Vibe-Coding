name: "Tavero"
link: "https://github.com/baccaraaa/tavero"
---

MCP server and CLI that scans a running React 19 app (Vite or Next.js) for UI drift: buttons, cards, colors, spacing and typography that no longer match each other. Gives the coding agent each fix with file and line references. Works with Claude Code, Cursor, Codex and any MCP client. Free, MIT.
