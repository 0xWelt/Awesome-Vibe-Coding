Free, local MIT MCP server that turns links into clean, AI-ready Markdown for Claude Code, Codex, Cursor and other MCP clients. Four tools: `youtube_transcript`, `youtube_playlist` (a whole playlist or channel, optionally with transcripts), `webpage_to_markdown` (main content only, absolute links) and `app_store_reviews` (up to 500 recent reviews with a rating histogram). Add it with `claude mcp add toolkb -- npx -y github:jack-reson8/toolkb-mcp`. No API key, no account, nothing sent to a third-party service.
