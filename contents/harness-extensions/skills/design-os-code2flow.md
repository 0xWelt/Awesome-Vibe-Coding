Free, source-available (PolyForm Shield) agent skill and CLI for Claude Code, Codex, Gemini CLI and Antigravity that statically reads a Next.js, React Router, TanStack Router, Expo Router, SwiftUI, Flutter or Jetpack Compose codebase, draws the real user-flow graph in Mermaid, and audits it with 11 UX checks (dead-end screens, missing loading or error states, unguarded auth routes), so you can see what a vibe-coded app actually does. Runs 100% locally with no network calls. Add it with `/plugin marketplace add jangtrinh/design-os-code2flow` in Claude Code.
