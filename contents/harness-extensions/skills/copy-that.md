MIT plugin marketplace for Claude Code and Codex with five taste-first Agent Skills for shipping what you vibe coded: [pro-motion](https://github.com/jack-reson8/pro-motion) renders a launch film in code and cuts it to the beat, [pro-launch](https://github.com/jack-reson8/pro-launch) takes an app from idea to launch (naming, references, style frames), [post](https://github.com/jack-reson8/post-skill) makes native-looking share images, [renhua](https://github.com/jack-reson8/renhua) writes Chinese copy that doesn't read as AI, and [skill-skill](https://github.com/jack-reson8/skill-skill) writes and lints skills against the Agent Skills spec. Add it with `/plugin marketplace add jack-reson8/copy-that` in Claude Code or `codex plugin marketplace add https://github.com/jack-reson8/copy-that.git` in Codex.
