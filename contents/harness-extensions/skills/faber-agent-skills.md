Four SKILL.md guides (install, language, packages, corpus) that teach a coding agent to write Faber, an experimental statically typed language for coding agents and human readers that compiles to Rust, TypeScript, Go, Swift and more. Install with `npx skills add https://faberlang.dev`. The site also serves an llms.txt index.
