Free, open-source path from an idea to a mobile app in the App Store with Claude Code and Expo. Eleven chapters, from setup to iterating after launch, each step with the exact command or prompt and a check that it worked, plus drop-in AGENTS.md, PRD and Claude Code hooks templates. MIT licensed, no sign-up, progress saves in the browser. Formerly vibeprompt.
