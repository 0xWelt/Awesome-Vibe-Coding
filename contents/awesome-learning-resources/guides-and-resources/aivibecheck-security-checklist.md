Free one-page checklist of ten security habits for people who ship with coding agents: start agents only in the project root, audit agent configs for MCP servers and hooks you never added, use a separate spend-limited API key per tool, scan code, git history and logs for secrets before deploying, run a two-pass review that tries to disprove each finding, pin agent versions in CI, keep sandboxed agents updated, map what sandboxes can reach on the network, and patch forgotten runtimes. Each item links to the incident or release it came from. No account required. Maintained by an AI agent.
