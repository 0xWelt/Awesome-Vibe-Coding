A cozy 3D co-op farming game for two in the browser, built by directing AI coding agents (mostly Claude Code, with OpenAI Codex for second opinions and screenshot reviews) from a written design document. The repository keeps the design, the economy simulation that sets every price and timer, more than 3,000 automated tests and an end-to-end run that drives two headless browsers through a co-op session. Node.js + Express + ws server, Three.js client with no bundler, phone layout, English and Bulgarian; self-hostable with npm or Docker, or playable at https://harvest-hollow.up.railway.app.
