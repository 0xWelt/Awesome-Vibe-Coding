An app icon inspiration library and set of AI tools for app makers, built by one developer directing Claude Code (311 of the first 384 commits are co-authored by Claude). It archives 18,000+ real App Store and Google Play icons along with every past version of each icon, and adds an AI app icon generator, an icon size exporter for iOS, Android and web, logo animation with Lottie export, and an App Store screenshot generator. Next.js 15 + React 19, available in 9 languages. Free to start, with paid plans.
