It covers terminal CLIs, IDEs, IDE extensions, web and cloud agents, mobile harnesses, agent SDKs, harness standards, code hosting, public cloud, containers, hosting and PaaS, the GitHub MCP server, vibe coding communities, projects, and learning resources. Supporting tools and supporting services are listed in [Awesome-Agent-Services](https://github.com/0xWelt/Awesome-Agent-Services).
