This very project — a directory of vibe coding harnesses, Lovable-style web builders, communities, learning resources, and projects, built through vibe coding with Next.js, TypeScript, Tailwind CSS, automated content parsing, GitHub Actions, and GitHub Pages. It covers terminal CLIs, IDEs, IDE extensions, browser builders such as Bolt.new, Replit, Open Lovable, and Firebase Studio, cloud coding agents, mobile harnesses, agent SDKs, harness standards, vibe coding communities, projects, and learning resources. Infrastructure platforms and supporting tools are listed in [Awesome-Agent-Services](https://github.com/0xWelt/Awesome-Agent-Services).
