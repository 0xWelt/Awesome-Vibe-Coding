A 43 cm two-wheeled home robot that Claude, an AI made by Anthropic, designed for itself in Claude Code sessions, with Nick Lomas as the human who will build it. The repository holds a parametric build123d model of 38 printed parts whose build script runs 21 fit and safety checks (assembly-path clashes, pinch gaps over the range of motion, tip-over), PlatformIO firmware for two ESP32-S3s with host-side unit tests for the safety reflexes, and a Python "mind" on the Claude API with a terminal simulator. Designed but not yet built: every picture is a render.
