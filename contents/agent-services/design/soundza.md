Agent skill and hosted MCP server for Soundza, a free library of sound effects, music loops and ambience in WAV and MP3. The skill lets Claude Code, Codex, Cursor and other agents search the library, play free previews so you can pick, generate a new sound effect from a prompt when nothing fits, and add the chosen sounds to a game, video or app.
