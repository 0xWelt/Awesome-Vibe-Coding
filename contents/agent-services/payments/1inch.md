Quote and execute intent-based (Fusion) and cross-chain token swaps, build and manage limit orders, and call any 1inch product endpoint - portfolio, spot prices, gas, Web3 RPC, and more. Includes Agent Skills with exact product_api recipes by API category (Trading & Liquidity, Wallet & Data, Market Data, Infrastructure). Public tools work without auth; execution tools require authentication from the 1inch Business Portal.

The vendor publishes an MCP server for this service.
