Boomerang Tasks is Roo Code's built-in orchestration system that breaks complex projects into manageable subtasks using specialized AI modes. It features an Orchestrator mode that automatically delegates work to appropriate specialized modes (Code, Architect, Debug), maintains isolated contexts for each subtask, and provides seamless workflow coordination.
