Hosted, read-only remote MCP server for SitePatent, a human-reviewed launch and discovery directory of startups, tools and online products. It lets Claude Code, Cursor, Codex and other MCP clients search the listed websites, SaaS and AI tools, read full listing profiles, find alternatives to a named product and see what is trending.
