Firecrawl is the context API for AI agents. It searches the web, scrapes pages into Markdown or structured JSON, and crawls and maps whole sites. It also interacts with dynamic pages in a real browser. [Firecrawl Alexandria](https://alexandria.firecrawl.dev) adds data from providers in finance, health, research, travel and other categories, called through the same API.

The vendor publishes an MCP server ([firecrawl-mcp-server](https://github.com/firecrawl/firecrawl-mcp-server)), a CLI ([firecrawl-cli](https://github.com/firecrawl/cli)), and Agent Skills ([firecrawl/skills](https://github.com/firecrawl/skills)) for this service.
