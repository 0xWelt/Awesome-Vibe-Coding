Connect to any MongoDB deployment (Community, Enterprise Advanced, local dev container via Atlas CLI or Atlas clusters) through a self-managed MongoDB using your connection string. Explore data, manage collections, optimize queries, and generate reliable code with MongoDB best practices. MongoDB Atlas is the managed cloud deployment of the same database.

The vendor publishes an MCP server for this service.
