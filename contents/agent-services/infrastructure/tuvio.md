Tuvio is a security scanner for apps built with AI coding assistants. It reads the GitHub repository (keys in the code and its git history, Supabase row level security in SQL migrations, Stripe webhooks, AI SDK misuse, vulnerable packages) and the live site, and an optional AI review writes a fix prompt for each finding.
