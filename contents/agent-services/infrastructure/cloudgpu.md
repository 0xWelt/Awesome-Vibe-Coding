CloudGPU rents GPUs by the minute and serves an OpenAI-compatible model API from one prepaid balance. An agent can quote, rent and destroy GPU instances, run commands or one-shot jobs with server-enforced spend, time and idle limits, and fetch the results over REST or MCP.

The vendor publishes an open-source MCP server ([cloudgpu-mcp](https://github.com/mrhy7176/cloudgpu-mcp)) and an Agent Skill ([SKILL.md](https://cloudgpu.app/skills/cloudgpu-compute/SKILL.md)) for this service.
