lavela is a deploy service (beta) that lets an AI agent, or a web console, put a GitHub repo on a live server and check on it afterwards. It builds the repo, runs it on a managed server, and adds managed Postgres, cron jobs, a custom domain you already own, and email authentication.

The vendor publishes an MCP server for this service.
