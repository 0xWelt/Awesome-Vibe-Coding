The service acts as a translation layer that connects your AI assistant to Checkmarx One APIs, enabling developers and security teams to interact with security operations directly via natural language. It provides context-aware remediation tools for code vulnerabilities, secrets, and IaC misconfigurations, along with scan workflows and project management - eliminating context switching and enabling immediate action on security findings within your IDE or terminal.

The vendor publishes an MCP server for this service.
