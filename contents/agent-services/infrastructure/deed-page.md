deed.page gives a vibe-coded HTML page, report, dashboard or static site a permanent public URL in one request, with no account, no email code and no expiry. An agent sends one `curl` PUT or POST (a single file, a folder tarball or inline JSON) and gets back `https://<slug>.deed.page` plus a token for updating the same slug later. The vendor publishes agent skills for this service.
