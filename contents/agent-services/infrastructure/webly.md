Webly is website hosting for AI agents. An agent publishes a vibe-coded website, or shares files and folders, at a live `*.webly.site` URL in seconds with no account needed to start; the person then signs in to claim it, and the agent keeps editing it over a hosted MCP server (Streamable HTTP, OAuth or API key) and publishes drafts the person approves.
