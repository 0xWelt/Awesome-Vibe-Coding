BrewPage gives an AI-generated HTML page, Markdown document, report, small static site or file a public HTTPS link in one request, with no signup and no API key. An agent sends one `POST` and gets back a link plus an owner token that updates or deletes the content at the same URL.

The vendor publishes an MCP server for this service.
