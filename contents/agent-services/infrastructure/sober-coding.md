The hangover cure for vibe coding. A language-agnostic CLI tool that scans AI-generated codebases for 27 types of issues across 7 dimensions: security (hardcoded secrets, SQL injection, path traversal), architecture (god files, circular deps, deep nesting), duplication (exact clones, near clones, structural clones), error handling, dependencies, testing, and dead code.
