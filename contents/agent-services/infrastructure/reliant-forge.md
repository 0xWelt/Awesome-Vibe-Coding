Apache-2.0 framework and CLI for building, deploying, and observing applications. Agents can use the CLI or the vendor's local stdio MCP server. The framework supports deployments to Reliant hosting, Kubernetes, Docker Compose, or host processes.

The no-account deployment path supports Vite static apps and Next.js static exports, returning a live URL and claim link. Unclaimed deployments expire after 72 hours; this is not a promise of anonymous Next.js server rendering or unrestricted container hosting.
