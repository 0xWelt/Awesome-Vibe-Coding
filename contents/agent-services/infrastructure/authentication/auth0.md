A single unified Auth0 skill that detects your framework, feature, and tooling, then loads the right reference guides for adding authentication - login, MFA, Organizations, ACUL, custom domains, branding, JWT validation, migration, and debugging - to any app.

The vendor publishes an MCP server for this service.
