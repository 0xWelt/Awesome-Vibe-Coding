Lookout is a VS Code extension that puts every AI coding agent session on one board in the side bar: which are working, finished or waiting on you, and what a waiting one asks, quoting its command, file, question or plan. One key jumps to a session's tab or terminal in any VS Code window on the machine, and a search covers every conversation, running or not.
