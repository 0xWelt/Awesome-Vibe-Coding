antiburn is a free, open-source, local-first desktop app for macOS, Windows, and Linux that checks coding agent sessions for common causes of token burn: sessions too deep, overpowered subagents, overthinking models, broken caching, and unused MCP servers, skills, and tools. It also shows live usage-limit meters and per-session context, cost, and tool breakdowns.
