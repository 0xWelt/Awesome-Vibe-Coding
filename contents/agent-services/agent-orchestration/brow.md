Brow is a macOS app that shows, in the MacBook notch, the usage limits of every Claude Code account you have: the 5-hour limit, the weekly limit and any model-specific weekly limit, each with the time until it resets. It also has a reset calendar and gives each account its own browser profile for signing in, so the other accounts stay signed in.
