Self-hosted worker that turns ready tickets from Jira, Linear, GitHub Issues, Trello, Asana, Azure DevOps or markdown into pull requests by running the coding agent you already use (Claude Code, Codex, Cursor or OpenCode) in fresh worktrees on your own machines and keys. One workspace.toml routes tickets across multiple repositories, the same worker runs cron automations and turns Sentry error groups into bugfix PRs, and review comments come back as commits on the same branch. Source-available (FSL-1.1-ALv2); free for interactive terminal use.
