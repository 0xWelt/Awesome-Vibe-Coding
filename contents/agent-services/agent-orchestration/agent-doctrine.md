agent-doctrine is a set of instructions, role prompts and skills that one sync installs into Claude Code, Codex, Cursor, OpenCode, Grok, Muse and Amp. The agent you talk to acts as a lead: it answers a written pre-code gate, plans, delegates each split to scout, implementer and reviewer subagents, and returns a tested PR for human approval.
