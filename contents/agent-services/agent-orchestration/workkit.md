workkit is a Claude Code plugin that runs a repo's GitHub Issues as the work pipeline for coding agents. Its skills interview you into a spec, build it, review it and ship it: a manager agent hands each issue to scout, worker and verifier subagents, labels track every stage from inbox to done, and nothing ships until you pass the QA step.
