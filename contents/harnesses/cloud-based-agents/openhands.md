OpenHands is an open-source platform for software engineering agents. Agent Canvas is the browser client for agent sessions. The Software Agent SDK is a Python library for building agents that work with code, and OpenHands Cloud is the managed service for hosted execution, integrations, and access control. Enterprise options cover licensed self-hosting.
