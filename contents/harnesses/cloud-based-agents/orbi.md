Orbi is an open-source (AGPL-3.0) coding agent that works from GitHub issues. With Orbi Cloud you install the GitHub App and connect a repository, and Orbi provisions a runner for it in a managed cloud sandbox. Label an issue `ai-ready` and it writes the change in an isolated worktree, opens a pull request, has a separate review session check the PR against the issue's acceptance criteria, merges only what passed that review, and cuts a tagged release. It also takes ops tickets such as deploys or investigations, posting every command it ran and its output back on the issue. The same agent can also be self-hosted.
