Open-source (MIT) AI code editor built on VS Code (Code - OSS). It runs Claude Code, Codex, OpenCode and Kimi over ACP, or OpenAI, Anthropic, Gemini, OpenRouter, Ollama and LM Studio directly, with hunk-level keep/undo of agent edits, a Git checkpoint every turn, MCP client support, an in-app browser and worktrees. Available for macOS, Windows and Linux.
