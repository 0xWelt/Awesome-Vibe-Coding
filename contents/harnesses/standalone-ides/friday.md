Friday is an open-source (MIT) desktop app for macOS, Windows and Linux that runs Claude Code, Codex, Cursor, Gemini CLI, GitHub Copilot, OpenCode and any other ACP agent side by side on your own computer. It has a task board, a git worktree per agent, diff review with line notes, and a hand-off to another agent when a tool hits its usage limit (the task moves with a record of what the first agent did and changed).
