Layerwise is a desktop workspace for building, previewing, and publishing full-stack web apps through AI conversations. Source files stay on the computer, with a built-in code editor, GitHub integration, and ZIP export. Projects include database, email authentication, hosting, analytics, and logs. It supports Agent Skills and local stdio or remote Streamable HTTP MCP servers. Available for macOS, Windows, and Linux (beta); proprietary with free and paid plans.
