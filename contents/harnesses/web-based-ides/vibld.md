Vibld is an open-source (Apache-2.0) AI app builder. Describe an app in plain English or start from a template, and Vibld writes a build plan and generates a plain React, TypeScript and Vite repo with no Vibld runtime. Built-in GitHub, Cloudflare and Docker integrations publish the result, and the project can be self-hosted or used through the hosted app at app.vibld.com.
