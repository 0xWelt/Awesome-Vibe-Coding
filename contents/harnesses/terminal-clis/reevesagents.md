reevesagents runs Claude Code, Codex, Kimi, OpenCode, Qwen, Hermes and other coding CLIs side by side, each in its own tmux window, so they keep running when you close the interface. You start runs and read or steer each agent from a terminal UI, a loopback-only web UI or the command line. An optional MCP server lets one trusted CLI start, read, steer and stop the others. Each CLI keeps its own login. Open source under Apache-2.0, installed with `npm install -g reevesagents` or Homebrew.
