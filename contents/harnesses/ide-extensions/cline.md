Cline is an open-source coding agent runtime you can use in an editor, a terminal, a desktop app, or your own product through the SDK. The editor extension and CLI share Plan and Act modes, multi-file edits with diffs and checkpoints, and a choice of Claude, GPT, Gemini, local models, or any OpenAI-compatible endpoint. Cline for Desktop runs the same agent without an editor.
