Kilo Code is an open-source AI coding agent for VS Code (and other Open VSX editors), JetBrains, the CLI, and the cloud. The same agent also ships as Kilo Desktop (beta) for macOS, Windows, and Linux. It includes Code, Plan, and Debug agents, bring-your-own-key and local models with no inference markup, and MIT-licensed source.
