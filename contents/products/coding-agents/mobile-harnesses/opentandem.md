OpenTandem is a workspace that puts the AI coding agents on all your computers in one page, so you can keep directing them from your phone after you leave the desk. It runs Claude Code, Codex, OpenCode and 15 more agent CLIs; you can switch agent or model inside the same task without losing the conversation or its files, see each agent's live quota, check which machine is online before sending a task, and preview a localhost page from the computer on your phone. Tasks, conversations and generated files are organized by project and open on any device. The command line and the Runner that executes on each computer are open source (AGPL-3.0); the web and mobile app are a hosted service. Connect a computer with `npx opentandem@latest remote`, then scan the QR code with your phone.
