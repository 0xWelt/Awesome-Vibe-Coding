Comate (文心快码, Baidu Comate) is Baidu's AI coding assistant. The [product introduction](https://comate.baidu.com/docs/) says you use it as a plugin in VS Code, JetBrains IDEs, and other editors, or as its own AI IDE.

The introduction's default agent is Zulu, which takes a programming task in conversation and carries it through. You can add custom agents, and a multi-agent mode splits a larger task across sub-agents. Rules and MCP connect a knowledge base or other tools. The same page lists completion, inline chat, and an AI IDE that combines the editor, chat, and a terminal, with a live front-end preview. Hosts named there include VS Code, JetBrains IDEs, Visual Studio, Xcode, and the Comate AI IDE on Windows, macOS, and Linux. Enterprise plans on that site include SaaS, hybrid, and private deployment.

The product home at [comate.baidu.com/zh](https://comate.baidu.com/zh) and its download URLs returned a script shell when fetched, so this entry quotes the docs introduction. [Wenxin Assistant](../../general-chat/wenxin-assistant.md) is Baidu's separate chat product.
