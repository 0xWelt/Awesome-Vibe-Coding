CodeBuddy (腾讯云代码助手) is Tencent Cloud's AI coding assistant, built on the Hunyuan code model. It ships as a standalone IDE, editor plugins, and a CLI. CodeBuddy IDE covers planning, design-to-code from Figma, and one-click sandbox deploy. Plugins add completion and chat in VS Code, JetBrains, and other editors. CodeBuddy Code is the terminal agent for tasks such as bug fixes, tests, and refactors.
