CodeArts (华为云码道) is Huawei Cloud's coding agent. The [product page](https://codearts.huaweicloud.com/) calls it the coding expert that understands a repository and carries work from a requirement through delivery. The [product introduction](https://support.huaweicloud.com/productdesc-codeartsagent/codeartsagent_pd_0001.html), updated 2026-09-29, lists the forms in one family.

码道 IDE is the AI-native IDE for Windows, macOS, Linux, and HarmonyOS PC. Plugins embed the agent in VS Code and JetBrains. The CLI is the terminal entry, with a TUI and a command line. 码道桌面端 is the desktop workbench for describing an app, a tool, content, or an automation in natural language. A browser workbench and a mini program are the other entries on that page. The introduction also describes agent teams, spec-driven development, repository understanding, skills, MCP, and scheduled automation from the workbench. The [download page](https://codearts.huaweicloud.com/download.html) lists the IDE, plugins, desktop beta, and CLI packages.

This file is the coding family, including the desktop workbench. [Xiaoyi Work](../../personal-agents/xiaoyi-work.md) is Huawei's separately named work assistant.
