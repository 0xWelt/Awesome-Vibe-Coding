SpaceApp is a self-hosted web workspace that runs OpenCode, Codex, Claude Code, Gemini CLI and other coding CLIs side by side as terminal panes in persistent rooms, with MCP servers and managed browser panes. It installs on Docker (Linux, macOS, Windows 11) with `npx --yes run-spaceapp@latest install`; `npm install -g run-spaceapp` adds the `spaceapp` management command.
