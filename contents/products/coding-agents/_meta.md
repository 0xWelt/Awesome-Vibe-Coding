---
title: Coding Agents
---
These are coding-primary products that run AI coding agents (local coding agents, standalone IDEs, IDE extensions, Lovable-style web builders, cloud coding agents, mobile apps, and agent SDKs). Coding, cowork, and computer-use remain capabilities, not separate classes. Agent SDKs stay as a subclass here. Local coding agents are local or self-hosted, and they typically include a terminal. They may also have a web UI or desktop app.
