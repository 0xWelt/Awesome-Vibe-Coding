AI coding agent for the terminal, built on OpenCode (MIT). It reads and edits your project, runs commands and tests, shows the diff, and can run headless or through ACP and MCP. One subscription covers Claude, GPT, Gemini and hundreds of other models, with limits that reset every 3 hours plus a weekly limit; plans start at $20/month. Install with `npm i -g imagera-code`.
