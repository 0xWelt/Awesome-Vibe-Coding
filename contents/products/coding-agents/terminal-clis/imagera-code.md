AI coding agent for the terminal, built on OpenCode (MIT). It reads and edits your project, runs commands and tests, and shows the diff; it can run non-interactively (`imagera-code run`, for scripts and CI) and can use MCP servers as tools. One subscription covers Claude, GPT, Gemini and hundreds of other models, with limits that reset every 3 hours plus a weekly limit; plans start at $20/month. Install with `npm i -g imagera-code`.
