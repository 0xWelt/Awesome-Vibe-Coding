Toad is a unified terminal UI for AI coding agents by Will McGugan, creator of Rich and Textual, on which it is built. Rather than being an agent itself, it finds, installs, and runs dozens of agents (Claude, Gemini, Codex, OpenHands, and more) through the Agent Client Protocol, with concurrent sessions and session resume. It pairs the agent with a fully working integrated shell (persistent state, full-color and interactive commands), a Markdown prompt editor with an `@` fuzzy file picker, and syntax-highlighted side-by-side diffs. Open source under AGPL-3.0.
