MiniMax Code is MiniMax's desktop app for programming and office work. The [about page](https://code.minimax.cn/about) says one desktop product has Coding and Work modes, and that it connects local files, tools, and a browser to carry a task through to a deliverable.

**Runtime:** macOS and Windows apps, a web app, a terminal, and mobile apps. The FAQ says the desktop app is for local files, code projects, and computer tools, and that the web app covers research and drafting without an install. You can hand a desktop task, with its context and files, to the cloud and follow it on the web, then sync a bound local directory back after you review the diff. Scheduled tasks depend on the desktop app: the computer has to stay awake and the app has to stay running.

**Acts on:** Coding mode keeps the project, terminal, and code context. Work mode is for research, documents, PPT, data, web pages, and other office tasks. The page also describes financial analysis, turning media into a site, and image, video, voice, and music generation. Local folder access and commands wait for your authorization.

**Extensions:** Skills, which the FAQ describes as a written method for a task such as a PPT or a data analysis, and plugins that connect tools such as Feishu, a browser, or a database. The comparison says it can connect to Chinese data services, including Hundsun and Qichacha.

**Notes:** This is the one MiniMax Code entry. The about page treats Coding and Work as peer modes of the same desktop. Scheduled tasks still need that desktop to stay awake. [MaxClaw](maxclaw.md) is the separate hosted Claw. agent.minimaxi.com/about redirects to this page.
