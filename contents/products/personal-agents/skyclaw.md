SkyClaw is an all-purpose assistant that lives on a 24/7 cloud computer. The [product page](https://skywork.ai/home_agent/skyclaw) says it stays on call, keeps a permanent memory, and can be reached through IM for long-running tasks.

**Runtime:** A cloud computer. The page says every task runs in an isolated cloud sandbox. Examples include a daily 9 a.m. news digest sent to WhatsApp, and a Telegram message that asks SkyClaw to inspect a production issue while you are away from the computer.

**Acts on:** That cloud computer, including the sites and repositories in those examples. The page says you set a goal once and SkyClaw carries out the multi-step work, and that it learns preferences over time.

**Extensions:** The IM channels in the examples, including WhatsApp and Telegram.

**Notes:** This entry is SkyClaw. [Skywork Desktop](skywork-desktop.md) is the desktop agent on the same site. The page also points at [OpenClaw](openclaw.md), the agent you run yourself.
