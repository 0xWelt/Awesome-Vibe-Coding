Kimi Work is Moonshot's desktop agent for knowledge work. It mounts local folders, browses with a browser extension, and runs scheduled jobs on the machine.

**Runtime:** Desktop apps for Mac and Windows. The [product page](https://www.kimi.com/products/kimi-work) says a built-in cron scheduler can call an agent or run Python or shell on a daily, hourly, or conditional trigger. Overnight runs need the setting that keeps the computer awake. [Remote Control](https://www.kimi.com/resources/kimi-work-remote-control), updated 2026-09-22, lets the Kimi App on Android or iOS 3.1.0 or later start a task, watch progress, and handle approvals. The task still runs on the computer. Files, credentials, and the environment stay on that machine, and the computer has to stay on and networked. The [release notes](https://www.kimi.com/help/kimi-work/release-notes) add remote control in 3.2.5 (2026-09-04).

**Acts on:** Local folders and the browser. The page says Kimi Work asks before it modifies, overwrites, or runs code in a local directory. The browser extension clicks, scrolls, and extracts across tabs, and can save results such as a local Excel file. Finished research can be turned into a PPT, PDF, or Excel file. The page also says A-share and Hong Kong market data is built in.

**Extensions:** The cron scheduler, the browser extension, and a cluster of specialist agents the page says it can coordinate on one job.

**Notes:** The product FAQ distinguishes Kimi Work from Kimi on the web, which it describes as the place for short conversations and lookups. This entry is the desktop agent. [Kimi](../general-chat/kimi.md) stays the conversation product.
