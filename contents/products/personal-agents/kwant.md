kwant is an open-source, self-hosted team of AI bots in one Rust binary. You run it on a computer you control (Mac app, Linux .deb/AppImage, Windows beta, or a VPS), and the bots keep working with spaces, handoffs, routines, and approval gates.

**Runtime:** One install runs the desktop app and/or `kwnt serve` on your machine or a VPS. Data lives under `~/.kwnt`. It works with the model providers and CLI logins you already have, plus local models. There is no hosted cloud tier from the project; you bring your own keys or local inference.

**Acts on:** A team of bots with separate spaces (work vs private), @mention handoffs between bots, scheduled routines, and human approvals before risky steps. Bots can use tools, MCP, and the accounts you connect.

**Extensions:** MCP servers, routines, approvals, and any OpenAI-compatible or local model. Import paths exist for bringing bots from other agent apps. License is AGPL-3.0 (commercial licenses available).

**Notes:** Positioned as an open-source self-hosted alternative to Grok Bot, Claude Duet and OpenAI dots. Official site [kwant.si](https://kwant.si); source [github.com/alexsergivan/kwant](https://github.com/alexsergivan/kwant). No token or crypto. This entry is the personal multi-bot runtime, not a coding harness.
