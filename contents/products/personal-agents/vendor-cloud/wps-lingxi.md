WPS Lingxi (WPS 灵犀) is Kingsoft Office's separately named AI office partner. You state a goal, and it plans the steps and returns a Word, Excel, or PPT file you can keep editing.

**Runtime:** A desktop client for Windows 10 or later and macOS 12 or later (Apple silicon and Intel), a web app, mobile apps, and a browser extension. The [homepage](https://www.lingxi.cn/) says the desktop client is the full product: deep file management, batch work, scheduled tasks, and multi-step jobs. The [docs](https://www.lingxi.cn/docs) add a local execution environment that can open local files and system actions, and a cloud environment that can use WPS cloud documents without reading the local disk.

**Acts on:** Local files, WPS documents, and the browser. The docs describe a browser assistant that connects Chrome or Edge, then reads, clicks, and fills forms on pages you authorize, and asks before a sensitive step. They also describe remote control of the desktop client from WeChat, WeCom, QQ, Feishu, and DingTalk.

**Extensions:** Built-in document, data, and slides skills, plus custom skills and project-level scheduled tasks. Permission mode is either 默认权限, which asks before deleting a file Lingxi did not create, or 完全访问. The docs say a normal chat starts in the default mode, and a scheduled task starts in full access unless you switch it. They also say a scheduled task cannot run more often than once an hour, and that in the beta they describe a task's default window is one week, with a maximum of 15 days.

**Notes:** This entry is the Lingxi product at lingxi.cn. The homepage presents it as its own assistant that delivers files you continue in WPS, not as the chat inside another window. The docs list an Office plugin that would call Lingxi from inside WPS as not yet available. Sign-in uses a WPS account. The homepage says download and basic tasks are free, and that expert mode spends 智点; the pricing page is the source for amounts.
