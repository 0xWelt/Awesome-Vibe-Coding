Skywork Desktop is the desktop agent for office, coding, and design work. It plans a task, works from folders you connect, and returns a file or a code change you can review.

**Runtime:** macOS 12 or later on Apple silicon, and Windows 10 or later, as stated on the [desktop page](https://skywork.ai/desktop/zh/index.html). That page says a connected local folder or code repository is the workspace, and that a report, research pass, check, or maintenance job can be set once and then run in the background. The Chinese site [tiangong.cn](https://www.tiangong.cn/) asks the same question in its Skywork Desktop FAQ: you choose the folders it may read or change.

**Acts on:** Those folders and repositories. The desktop page lists editable documents, decks, spreadsheets, research notes, responsive sites, visual assets, and reviewable code changes. Plans, diffs, and deliverables stay visible in the task.

**Extensions:** Skills and a model router. The desktop page says you can pick Claude, GPT, Gemini, DeepSeek, or another listed family, or let Skywork choose per step. Specialist sub-agents can research, analyze, write, build, and check in parallel.

**Notes:** This entry is Skywork Desktop only. [SkyClaw](skyclaw.md) is the separate assistant on a 24/7 cloud computer. The same site keeps browser Skywork as the upload-based web product. Coding harnesses stay in [Coding Agents](../coding-agents/). The desktop page says which models are available can depend on the account and plan.
