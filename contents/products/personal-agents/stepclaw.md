StepClaw is StepFun's cloud agent. The [deploy page](https://chat.stepfun.com/openclaw) calls it an AI agent that understands an instruction and carries the task out. It says Leap AI deploys StepClaw to the cloud in one click, with no complex configuration, so you get a 24/7 assistant.

**Runtime:** That one-click cloud deployment. The page says the product is currently in beta and asks you to pay attention to data security while using it.

**Acts on:** Tasks you hand the deployed assistant.

**Notes:** This entry is StepClaw. [StepFun Desktop](stepfun-desktop.md) is the desktop partner. [OpenClaw](openclaw.md) is the agent you run yourself.
