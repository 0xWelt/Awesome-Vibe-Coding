Manus is a general-purpose agent that carries out a task and returns a result. Its docs describe it as a virtual colleague with a computer of its own, for work you would otherwise supervise step by step.

**Runtime:** The Manus app on the web. Each task can run in a sandbox: a virtual computer with internet access, a persistent file system, and the ability to install software and create tools for that task. [Manus Browser Operator](https://manus.im/features/manus-browser-operator) is a browser extension that works in your current browser session and logged-in tabs.

**Acts on:** The sandbox computer and the websites it opens, plus services you connect. The [welcome doc](https://manus.im/docs/introduction/welcome) names Gmail, Notion, Slack, and GitHub as examples. Browser Operator is described for multi-step browsing such as research, form filling, and booking logistics.

**Extensions:** Connectors for apps you already use, the sandbox's own browser and software, and the Browser Operator extension. This entry does not list every connector.

**Notes:** The same product site also offers creative generators (slides, design, and similar). This entry covers the general agent. Browser Operator is an additional way to launch browsing work; the primary home here is the Manus task runtime. [Cue](cue.md) is the separately named personal-agent product from the same company.
