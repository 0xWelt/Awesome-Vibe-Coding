DuClaw is Baidu Intelligent Cloud's hosted agent for consumers with no technical background. The [product description](https://cloud.baidu.com/doc/DuClaw/s/Rmmst7301), updated 2026-04-14, says it uses a model and a skill system to carry out tasks, and that it can bind mainstream messaging apps for office, creation, and everyday use.

**Runtime:** Cloud hosting with multi-tenant isolation. The description says there is no image, server, or API-key setup. The [changelog](https://cloud.baidu.com/doc/DuClaw/s/Pmo2q1ewy) records the launch on 2026-03-11, then scheduled tasks, a skill market, messaging apps, and a browser plugin. The subscribe page at [cloud.baidu.com/product/duclaw.html](https://cloud.baidu.com/product/duclaw.html) returned only a subscription step, and its dialog said the activity was too busy to continue.

**Acts on:** Tasks you describe, files, and the messaging channels you connect. The description lists Feishu, DingTalk, WeCom, WeChat, and Weibo, plus scheduled jobs such as collecting information, calendar reminders, and syncing data. It also says DuClaw can pair with a Xiaodu device. The April 2026 changelog says a browser plugin can open and operate a browser, including a login QR code or a captcha.

**Extensions:** Preset skills, skills you create and publish, and a personality file for how it addresses you and how it formats output. The description says you can choose among mainstream models, and names GLM-5 and MiniMax-M2.5.

**Notes:** This entry is DuClaw, the hosted cloud agent. [Wenxin Assistant](../general-chat/wenxin-assistant.md) is Baidu's chat, and [DuMate](dumate.md) is the on-device assistant. The [billing doc](https://cloud.baidu.com/doc/DuClaw/s/Amnzoj4xm) lists the monthly subscription tiers. Use that page for current prices.
