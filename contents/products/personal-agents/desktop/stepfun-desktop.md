StepFun Desktop (阶跃AI桌面伙伴) is StepFun's agent on the operating system. It looks for work and can start a task when a condition you set is met.

**Runtime:** The desktop app from the [download page](https://www.stepfun.com/download). The same page is also served at [chat.stepfun.com/download](https://chat.stepfun.com/download). It describes an agent that operates web pages and files, saves what it gathers into local files, and renames or classifies local files.

**Acts on:** Local files and sites it browses, including social and data sites named on that page. It can add a reminder to the system calendar from a sentence. Timed tasks fire at the time you set. A task can also start when its condition is met, without a new message.

**Extensions:** Skills that ship with the app, and workflows you turn into a skill so the same instruction can be triggered again. The page says you can set its character, preferences, and how the interface looks.

**Notes:** This entry is the desktop partner on the download page. [StepClaw](../cloud-computer/stepclaw.md) is the separately deployed cloud assistant. The download page does not use a separate nickname for the desktop partner.
