Gemini for desktop is Google's Gemini app for Windows and macOS. It is one desktop app, not a separate work product.

**Runtime:** The [desktop page](https://gemini.google/desktop/) offers downloads for macOS and Windows. It says the Windows app runs on Windows 10 or later, on x64 and ARM.

**Acts on:** Flip to Task to run multi-step chores in the background, then approve each action. The page says Tasks can clean up folders or summarize local files into Google Docs and Sheets, and can pull from Gmail, Drive, Docs, and Calendar into the desktop workflow.

**Extensions:** Connected Google apps on that page. The [next-evolution post](https://blog.google/innovation-and-ai/products/gemini-app/next-evolution-gemini-app/) describes Gemini Spark as an in-app agent for around-the-clock help, and says the desktop app will integrate Spark so it can operate on the local machine. Spark is a capability inside the Gemini app, not a separately named desktop product.

**Notes:** This entry is the desktop app. The conversation product stays in [Gemini](../../general-chat/gemini.md). This is not Gemini CLI.
