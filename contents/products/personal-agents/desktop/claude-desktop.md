Claude Desktop is the Claude app for Mac, Windows, iOS, and Android. The [download page](https://claude.com/download) calls it all of Claude in one app.

**Runtime:** Web, desktop, and mobile. The [Cowork is now Claude article](https://claude.com/resources/articles/cowork-is-now-claude) says Cowork and chat are one Claude, rolling out first to Pro, Max, and Ultra in the Claude app on web, desktop, and mobile. Nothing extra has to be turned on.

**Acts on:** The [help article](https://support.claude.com/en/articles/16761823-claude-cowork-and-chat-are-one-claude) says chat and Cowork are one conversation. Claude can answer a quick question, and it can take on research, reports, spreadsheets, and presentations and hand them back as files you can edit. There is no mode to choose first.

**Extensions:** What used to be only in Claude Cowork is available from any conversation in that new experience. The same article says Claude picks the tool for the ask.

**Notes:** This entry is the unified app. The conversation product stays in [Claude](../../general-chat/claude.md). [Claude Duet](../cloud-computer/claude-duet.md) is a separately named standalone proactive agent under Cloud Computer, not this desktop app. Claude Code stays in Coding Agents.
