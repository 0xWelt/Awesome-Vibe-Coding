ChatGPT Desktop is the new ChatGPT app for macOS and Windows. It puts Chat and Work under ChatGPT, with Codex as another view in the same app.

**Runtime:** The [download page](https://chatgpt.com/download) is the installer for Windows, Mac, iPhone, and Android. The [move-to-the-new-desktop article](https://help.openai.com/en/articles/20001276-moving-to-the-new-chatgpt-desktop-app) says the new desktop app includes Chat and Work under ChatGPT, alongside Codex, on macOS and Windows. Updating the Codex app turns it into this app. The previous desktop app can remain installed as ChatGPT Classic.

**Acts on:** Chat is for questions, search, and conversations. Work is the agent for longer multi-step work and finished deliverables: research, analysis, and documents, spreadsheets, presentations, reports, and Sites. The [Work and Codex article](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex) says Work is also on web and mobile for eligible paid plans, and that desktop Work can use local files and desktop apps when the plan and workspace allow it. Cloud Work chats sync across web, mobile, and desktop. Codex stays a separate view for local folders, repositories, terminals, and developer tools.

**Extensions:** On desktop, ChatGPT and Codex are menu choices. Inside ChatGPT, Chat and Work are a toggle, and those chats share Recents. Voice is available for Work and Codex in the desktop app.

**Notes:** This entry is the unified desktop app. The conversation product stays in [ChatGPT](../../general-chat/chatgpt.md). [Dots](../cloud-computer/dots.md) is a separately named always-on agent under Cloud Computer, not this desktop app.
