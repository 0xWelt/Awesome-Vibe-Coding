Kimi Claw is Moonshot's always-on agent for deploying OpenClaw. The [product comparison](https://www.kimi.com/help/others/product-comparison) describes it as 7×24 cloud automation that connects to Feishu, WeChat, and similar chats. That page labels the runtime 云端（无需服务器）.

**Runtime:** The [Kimi Claw page](https://www.kimi.com/bot) deploys OpenClaw to a cloud server so it stays online 7×24, with long-term memory and scheduled tasks. The same page can also associate an OpenClaw you already run, install one on your computer for local files, or place one on an idle Android phone. The comparison treats the cloud-resident bot as the Kimi Claw line, and places local files and desktop automation with Kimi Work.

**Acts on:** Tasks you give it in Kimi, and the chat tools it is connected to. The page says a new deployment is configured with a Kimi model and a skill library, and that it can take on tasks from those chats.

**Extensions:** Skills included at deploy time, and chat channels. The [deploy guide](https://www.kimi.com/help/kimi-claw/overview) says you create a Kimi Claw from the bot page, then connect WeChat, Feishu, WeCom, and similar under chat channels. The page description also names Claw groups, in beta, where several agents and people share one group.

**Notes:** This entry is Kimi Claw. [Kimi](../general-chat/kimi.md) is the conversation product, and [Kimi Work](kimi-work.md) is the desktop agent. The same comparison names Kimi Code for writing and maintaining a repository from the command line or a VS Code plugin. [OpenClaw](openclaw.md) is the agent you run yourself.
