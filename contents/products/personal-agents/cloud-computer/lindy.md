Lindy is an AI employee that works across the tools you connect. It handles recurring jobs, and it waits for your OK before an action that has an effect outside the account.

**Runtime:** You reach the same employee from Slack, iMessage, email, meetings, and a Chrome extension. The [docs](https://docs.lindy.ai/) say Microsoft Teams is still listed as coming soon. The [product page](https://www.lindy.ai/) says an admin installs it in Slack and teammates mention it in a channel it has joined. Routines run on a schedule or when something happens, including overnight.

**Acts on:** Connected tools, meetings, and files. The docs describe inbox and calendar help, meeting follow-up, research, reports, and CRM updates. The product page says lookups can proceed, and anything with outside impact waits until you approve it or you later tell Lindy to run that job on its own. Browser control is described there for Pro and above when a tool has no integration.

**Extensions:** More than 1,500 integrations, plus hosted MCP servers, skills you save as playbooks, and routines. The product page says a missing tool can be driven in the browser or built as an integration. Memory is something you can inspect, and you choose what stays personal versus what the team can see.

**Notes:** The product FAQ says plans start at $49.99 per user per month after a $50 credit start, and that Pro and Max add credits and connected inboxes. Use the pricing page for the live list. The docs say shared Slack changes can be set to need approval. This entry is the one Lindy employee, not a separate file for each role the marketing page names.
