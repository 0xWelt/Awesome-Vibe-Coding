MaxClaw is MiniMax's hosted cloud agent, built on OpenClaw. The [product page](https://agent.minimaxi.com/activity/max-claw) says you deploy it in the browser in about 10 seconds, without a server, Docker, or an API key, and that MiniMax M2.7 drives it.

**Runtime:** MiniMax-hosted cloud. The page says a new user gets 50 GB of cloud space for long-term memory and files, and that expert agents stay online 7×24, including inside Feishu, DingTalk, and other chat apps. You start it from MiniMax Agent by choosing MaxClaw and deploying.

**Acts on:** Research and analysis, files, the browser, and code execution, as the page FAQ lists them. Built-in tools also cover image and video generation. The FAQ describes MaxClaw as a 24/7 assistant you can leave repeating work with.

**Extensions:** Built-in tools and expert skills. The page says you can create an expert in natural language and use 16,000+ expert skills from the MiniMax Agent ecosystem. Chat connections named on the page include Feishu and DingTalk; the FAQ says other chat platforms can be connected as well.

**Notes:** This entry is MaxClaw, the hosted Claw. [MiniMax Code](../desktop/minimax-code.md) is the separate desktop app, with Coding and Work modes. OpenClaw stays in [Self-hosted](../self-hosted/openclaw.md).
