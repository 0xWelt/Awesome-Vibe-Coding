QwenWork (千问办公) is Alibaba's AI office platform. You describe the outcome, and it plans the work, uses your files and tools, and returns a finished file.

**Runtime:** Native apps for Mac and Windows, and a web app. The [Aliyun overview](https://help.aliyun.com/zh/qwenwork/product-overview/) says the same product also opens inside DingTalk, and that a desktop login can read documents, spreadsheets, images, and video already on the local disk and save the result back to a path you choose. The Chinese site is [qwenwork.cn](https://qwenwork.cn/).

**Acts on:** Local files you point it at, DingTalk, and the browser. The Aliyun overview says it can deliver PPT, Word, Excel, web pages, reports, and multimedia, and that browser automation (clicks, input, and collection) is available in the desktop client. The [English product page](https://qwenwork.ai/) says high-risk actions wait for approval, and that a scheduled task can return a daily or weekly brief.

**Extensions:** Skills and connectors. The English page says QwenWork loads a skill for the task. The Chinese site describes a skill market, expert kits, and enterprise IM for messages, attendance and approvals, calendars, docs and sheets, knowledge bases, and mail. The Aliyun overview identifies the DingTalk workspace as that IM entry, and says a cloud scheduled task can push its result to a DingTalk message.

**Notes:** This entry is QwenWork, the office platform. It is built on the Qwen model family, and the Aliyun overview contrasts it with a chat tool that only answers. Qoder is documented by Aliyun as a separate coding product and is not this entry. Coding harnesses stay in [Coding Agents](../../coding-agents/).
