AstronClaw is iFlytek's always-on assistant. The [quickstart](https://www.xfyun.cn/doc/spark/AstronClaw/01-快速上手.html) describes a 24-hour AI assistant: one click deploys a dedicated cloud server, flagship models, and skills.

**Runtime:** Cloud hosting, plus a desktop client for local runs. The [advantages page](https://www.xfyun.cn/doc/spark/AstronClaw/02-核心优势.html) says cloud hosting stays up 7×24, including scheduled tasks, and that a task can run on the local client or in the cloud. Local mode can read and write files on that computer and run local commands after you approve. Cloud mode is what you use from a browser on another device.

**Acts on:** The conversation, files you drop in, and channels you bind. The quickstart names PDF, Word, and Excel. The advantages page names WeChat, WeCom, Feishu, DingTalk, QQ, and Weibo. A scheduled task can repeat daily, weekly, monthly, or at a custom time, and can push to a bound channel.

**Extensions:** Skills from the market, from a conversation, or from a file you upload, plus agents and teams. The quickstart says the default agent is Astron Agent and the default team is Astron Team, which assembles members for the task. Memory is on by default, and the quickstart says memory files sync in the cloud.

**Notes:** This entry is AstronClaw. [iFlytek Spark](../../general-chat/iflytek-spark.md) is the chat assistant. The [FAQ](https://www.xfyun.cn/doc/spark/AstronClaw/07-常见问题.html) says v1.2 can include a 7-day trial, and that continued use needs the basic or professional subscription. Use that page for current prices. OpenClaw stays in [Self-hosted](../self-hosted/openclaw.md).
