Genspark Super Agent is the agent on Genspark that takes a whole job. You describe the finished thing, attach the files, and it returns something you can open.

**Runtime:** The Genspark home page and Agents → General → Super Agent, on desktop web, a phone browser, and the app. The [Super Agent guide](https://www.genspark.ai/helpcenter/super-agent) says New Super Agent gives each project its own cloud computer, separate from your computer and from other projects. A turn can run for up to two hours, and closing the tab does not stop it. Reopen the project from Tasks to see where it got to. Classic mode, still available, has no cloud computer behind the run.

**Acts on:** Files you attach, connectors you leave on, and the project computer. On that computer the guide says the agent can run Python and shell, work with files, read public pages, and preview HTML. Delivered files stay in the project. The guide says the computer is temporary: when it is recycled, the conversation cannot continue, and files already delivered remain.

**Extensions:** Skills in New Super Agent, saved from a workflow and run again with `/` or the composer menu. Connectors can be turned off per chat, or remembered by the browser for later chats. New images, video, and music ask you to confirm before they generate.

**Notes:** The homepage is where a task starts. This entry is Super Agent, the general agent that returns files. The guide says the project's cloud computer is not the separate Claw cloud-computer subscription. A free account usually starts in Classic and can switch New Super Agent on; paid plans default to New.
