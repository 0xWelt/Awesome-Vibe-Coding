Viktor is an AI employee that lives in Slack and Microsoft Teams. The team messages him like a colleague, and he does the work on a computer of his own.

**Runtime:** Slack, Microsoft Teams, the web app at app.viktor.com, and Discord. The [product FAQ](https://viktor.com/) says each person gets an isolated compute environment, and that Viktor writes and runs code there. Scheduled tasks run from that cloud computer. The [legal notice](https://viktor.com/impressum) names the provider as Zeta AI, Inc.

**Acts on:** Tools you connect, and the channels he is invited to. The FAQ lists reports, spreadsheets, web apps, CRM updates, and code among the work he returns in the thread. He asks for confirmation before high-stakes actions such as sending email or deploying to production. Admins decide which tools need approval.

**Extensions:** More than 9,800 tools, named on the product page, including Salesforce, HubSpot, Linear, Notion, Jira, Stripe, GitHub, and Google Drive. Skills are notes he writes about how the team works. Integrations can be shared with the workspace or, in Slack, kept to people you add.

**Notes:** The [facts page](https://viktor.com/ai-instructions) says a human approves sensitive actions by default, and that Private Mode for per-user isolation is not shipped yet. Viktor reads the channels and chats he has been added to. The same page says the Team plan is priced per workspace. Use the pricing page for the current credit amounts.
