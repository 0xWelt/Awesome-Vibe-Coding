Security scanner for AI-generated code. Paste a live app URL or a public repo and it finds what AI coding tools ship most: hardcoded keys, routes that render without a login, Supabase tables readable with the public key, injection. 15 rules mapped to the OWASP Top 10, a free GitHub Action that comments on every pull request, and a rewriter that applies and verifies the fix. Built from scanning 2,148 AI-built repos and probing 4,740 live apps; the anonymised dataset is public.
