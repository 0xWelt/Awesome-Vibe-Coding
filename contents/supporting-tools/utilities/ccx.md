ccx pairs a Claude Code session with a Codex thread and syncs context both ways: messages, condensed tool calls, the latest plan and git status. When one side hits its usage limit, click ⇄ in the macOS menu bar and the other continues the task; each update is delivered once, and it warns when either side's 5-hour window passes 90%. On the Codex side it uses only the official app-server API. Install by pasting the one-line prompt from the README into Claude Code or Codex (MIT, local, no account).
