VibeDesk is an open-source (MIT) Windows desktop app for Claude Code. It runs several Claude Code sessions in real terminals side by side, shows each session's status (working, waiting for you, done), and turns permission prompts into cards you can answer on the PC or from a paired phone. It also includes a Git window, optional per-session worktrees, a live preview for local dev servers, and per-project memory stored as Obsidian-compatible Markdown that Claude reads and writes over MCP. It launches your own installed Claude Code CLI, so your plan and settings carry over.
