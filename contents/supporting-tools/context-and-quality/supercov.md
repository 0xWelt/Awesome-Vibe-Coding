supercov wraps the test command a project already runs and reports line, branch and MC/DC coverage per test, so a coding agent knows which code to test next. It works with JavaScript, TypeScript, Python, Ruby, Rust, Go, Java and Kotlin suites and needs no config file or custom reporter. Coverage runs locally; the optional quality and security checks send source files to TypeSafe when TYPESAFE_API_KEY is configured. Run it with npx supercov -- npm test (MIT).
