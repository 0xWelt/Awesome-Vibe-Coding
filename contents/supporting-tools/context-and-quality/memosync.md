MemoSync is a local web workbench for Claude Code, Codex, and Pi that makes coding-agent memory reviewable. Developers approve proposed memory changes, choose each turn's working memory before the agent starts, see which memories a reply cites, and get a post-turn audit of which memories were followed or violated, across sessions.
