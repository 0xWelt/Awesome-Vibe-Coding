Vibe Coding Rules is a set of copy-paste rules files for 20 beginner project types, including Phaser and Godot games, Discord and Telegram bots, Next.js, Supabase, Expo and FastAPI. Each project has an `AGENTS.md`, a `CLAUDE.md` that imports it with `@AGENTS.md`, and two Cursor `.mdc` rules, combining shared working rules (plan first, smallest change, no secrets in code, ask before destructive commands) with six rules for the stack. The repo also has 7 Claude Code `SKILL.md` examples and a Markdown file of 21 coding prompts. Free, no signup, MIT licensed.
