Agent Standup shows the Claude Code, Codex and Mistral Vibe sessions on your computer as a live, animated team call: the lead and each sub-agent are drawn characters at their desks, they speak their updates aloud, and the one at work shares its screen with the real terminal output or diff. Tiles flag who is working, stuck on a long command, gone quiet, waiting on another agent or waiting for you, with tokens per agent, and a board lists every session. It reads only the files the agents already write on disk, costs no tokens, and is MIT-licensed as a VS Code extension (Marketplace and Open VSX), an npm CLI, a Claude Code plugin and a macOS app.
