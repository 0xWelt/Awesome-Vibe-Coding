Ultra Mod is an all-in-one mod pack for Claude Code: a usage limits and context HUD, a guard with undo for `rm -rf` and `git reset --hard`, `.env` and secret protection, and a receipt for every turn. The HUD is one line above the prompt with context use and the 5-hour and weekly limits with reset times. The receipt under each answer lists the files changed, the commands run and whether tests passed. It makes no network requests, is MIT-licensed, and needs Claude Code 2.1.287 or later.
