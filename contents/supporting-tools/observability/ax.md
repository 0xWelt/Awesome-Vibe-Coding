ax is a local-first telemetry and recall graph for AI coding agents. It ingests Claude Code, Codex, Cursor, OpenCode, and Pi session history into SurrealDB so developers can inspect turns, tool calls, skills, cost, dispatches, and OTLP telemetry from a CLI, dashboard, or read-only MCP server.
