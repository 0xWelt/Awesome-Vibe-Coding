---
name: "Lookout for VS Code"
link: "https://github.com/nimrod-teich/lookout"
---

Lookout is a VS Code extension that puts every AI coding agent session on one board in the side bar: which are working, finished or waiting on you, and what a waiting one asks, quoting its command, file, question or plan. One key jumps to a session's tab or terminal in any VS Code window on the machine, and a search covers every conversation, running or not. Cards show tokens and API list-rate price for Claude Code and Codex, and the board shows their 5-hour and weekly usage limits. It works with Claude Code, Codex and Copilot CLI, reads only the files the agents already write on disk (no hooks, no credentials, nothing sent anywhere), and is MIT-licensed on the VS Code Marketplace and Open VSX.
